# სასწავლო პორტალი (ORIONI)

## აღწერა

**ORIONI** არის React + Django REST Framework სასწავლო კურსების პლატფორმა, სადაც:

- **მასწავლებელი** ქმნის და მართავს საკუთარ კურსებს (სათაური, აღწერა, სილაბუსი, ფასი, ხატულა/სურათი, დაწყების თარიღი, ხანგრძლივობა), ხედავს ვის ჩაერიცხა მის კურსზე (სახელი, ელფოსტა, ტელეფონი).
- **მოსწავლე** ათვალიერებს ხელმისაწვდომ კურსებს (ძიება, ფილტრაცია კატეგორიით, დალაგება), ირიცხება/იშლება კურსიდან და ხედავს საკუთარი კურსების სიას.
- ორივე როლს აქვს პირადი პროფილი (მომხმარებლის სახელი, ელფოსტა, ტელეფონი; მასწავლებელს დამატებით - აღწერა/გამოცდილება, რომელიც მოსწავლეებს უჩანთ კურსის დეტალებში).

წვდომა API-ზე დაცულია JWT ავთენტიფიკაციით (access + refresh ტოკენები), ხოლო კონკრეტული მოქმედებები (კურსის შექმნა, რედაქტირება, ჩარიცხვა) - როლზე დაფუძნებული Permission კლასებით.

## ტექნოლოგიები

**Backend:**
- Python, Django, Django REST Framework
- djangorestframework-simplejwt (JWT ავთენტიფიკაცია)
- django-filter (ფილტრაცია)
- django-cors-headers (CORS)
- PostgreSQL (production) / SQLite (ლოკალურად)
- Pillow (სურათების დამუშავება), Gunicorn + WhiteNoise (production სერვერი/static ფაილები)
- Docker

**Frontend:**
- React (Create React App)
- React Router
- Axios (API ინტეგრაცია, access/refresh ტოკენების ავტომატური განახლება)
- საკუთარი CSS (Responsive დიზაინი)

## ფუნქციები

- რეგისტრაცია როლის არჩევით (მოსწავლე / მასწავლელი), ავტორიზაცია, გამოსვლა
- JWT Access/Refresh ტოკენები, Protected Routes (Frontend + Backend)
- კურსების სრული CRUD (შექმნა, ნახვა, რედაქტირება, წაშლა) - მხოლოდ ავტორისთვის
- სილაბუსი, დაწყების თარიღი და ხანგრძლივობა (კვირებში) კურსის დეტალებში
- ძიება სათაურით/აღწერით, ფილტრაცია კატეგორიით, დალაგება ფასის/თარიღის მიხედვით
- გვერდებად დაყოფა (Pagination)
- კურსზე ჩარიცხვა/ჩარიცხვის გაუქმება (მხოლოდ მოსწავლეს), ჩარიცხულთა სია (მხოლოდ ავტორ-მასწავლებელს - სახელი, ელფოსტა, ტელეფონი)
- პირადი პროფილის რედაქტირება (სახელი, ელფოსტა, ტელეფონი; მასწავლებელს დამატებით - აღწერა)
- სურათის ატვირთვა კურსისთვის
- მთავარ გვერდზე მასწავლებლების კარუსელი (სახელი, სტატუსი/გამოცდილება, საკონტაქტო ინფო, კურსების რაოდენობა)
- პროფილის გვერდზე მოსწავლისთვის „ჩემი კურსების ისტორია“ - ჩამოშლადი/აკეცვადი სექცია ჩარიცხვების სრული სიით
- სოციალური ქსელების ბმულები ნავიგაციაში
- Responsive UI, Loading/Error/Empty States
- Production Deployment Render-ზე (Docker + PostgreSQL + Static Site)
